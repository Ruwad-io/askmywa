First release: WhatsApp for Claude and other AI assistants, as a single program for Mac, Windows, Linux and Raspberry Pi.

*[Version française plus bas.](#en-français)*

## Install

| You have | Do this |
|---|---|
| Claude Desktop on Mac or Windows | Download **`askmywa-0.1.0.mcpb`** below, double-click it, then ask Claude: *Connect my WhatsApp.* |
| Linux, Raspberry Pi or Mac, with a terminal | `curl -fsSL https://github.com/Ruwad-io/askmywa/releases/latest/download/install.sh \| sh` |
| Homebrew | `brew install ruwad-io/tap/askmywa`, then `askmywa install-service` and `askmywa link` |
| Anything else | The archive for your system below; see the [README](https://github.com/Ruwad-io/askmywa#install-without-the-extension-mac-windows-linux) |

Linking takes a code typed on your phone (WhatsApp > Linked devices > Link a device > *Link with phone number instead*): no QR code, no screen needed.

## What it does

- Reads, searches and sends your WhatsApp messages from Claude Desktop, Claude Code, Cursor or any MCP client.
- Keeps the archive on your computer, in a local database. Nothing reaches the assistant unless it asks for it.
- Shows real names: from your address book, merged across phone numbers and WhatsApp's hidden identifiers.
- Search ignores case and accents: `ecole` finds `école`.
- **Nothing is sent without your approval.** Every send shows a preview (recipient, group or not, content) first.
- Files can only be sent from one folder you choose.
- Runs in the background (launchd, systemd or a Windows scheduled task) and keeps working after a restart.
- `disconnect_whatsapp` unlinks the computer and can delete the archive, for a clean uninstall.

## Good to know

- This is not a WhatsApp product. It connects as a linked device, like WhatsApp Web, through an interface WhatsApp has not opened officially; WhatsApp could restrict an account that uses it.
- A received message could try to trick the assistant. Read each send preview before approving it.
- The macOS binaries are signed and notarized by Apple. The Windows build is not code-signed yet: if SmartScreen warns, choose *More info* > *Run anyway*.
- Every download is listed in `checksums.txt` (SHA-256).

## En français

Première version : WhatsApp pour Claude et les autres assistants IA, en un seul programme pour Mac, Windows, Linux et Raspberry Pi.

**Installer**

- **Claude Desktop sur Mac ou Windows** : téléchargez **`askmywa-0.1.0.mcpb`** ci-dessous, double-cliquez dessus, puis demandez à Claude : *Connecte mon WhatsApp.*
- **Linux, Raspberry Pi ou Mac, dans un terminal** : `curl -fsSL https://github.com/Ruwad-io/askmywa/releases/latest/download/install.sh | sh`
- **Homebrew** : `brew install ruwad-io/tap/askmywa`, puis `askmywa install-service` et `askmywa link`.

La liaison se fait avec un code tapé sur le téléphone (WhatsApp > Appareils connectés > Connecter un appareil > *Connecter avec un numéro de téléphone*) : pas de QR code, pas besoin d'écran.

**Ce que ça fait** : lire, chercher et envoyer vos messages WhatsApp depuis Claude. Les messages restent sur votre ordinateur, la recherche ignore les majuscules et les accents, et **rien n'est envoyé sans votre accord** : chaque envoi passe par un aperçu.

**À savoir** : ce n'est pas un produit de WhatsApp, qui pourrait restreindre un compte qui l'utilise. Lisez chaque aperçu avant d'accepter un envoi. Le programme Windows n'est pas encore signé : si SmartScreen s'affiche, choisissez *Informations complémentaires* > *Exécuter quand même*.

Le guide complet est dans le [README en français](https://github.com/Ruwad-io/askmywa/blob/main/README.fr.md).
