Claude Desktop · Mac and Windows

One download. One code.

No terminal, no QR code. You link your computer the way you'd link WhatsApp Web, by typing a code on your phone.

Your code · valid 2 minutes
K7QM-2XPA

Claude shows you a code like this one. Each code is new and works once.

  1. Download the extension

    One file, askmywa.mcpb, for Mac and Windows.

  2. Double-click it

    Claude opens and asks you to confirm the install.

  3. Say “Connect my WhatsApp”

    In a new chat. Give your number with its country code. Claude asks for permission to use askmywa: choose the permissions you are comfortable with.

  4. Type the code on your phone

    WhatsApp › Linked devices › Link a device › Link with phone number instead

ChatGPT and Codex

Install for ChatGPT or Codex.

askmywa also works in the ChatGPT app on a Mac, and in Codex. There is no file to double-click for ChatGPT yet: you paste one line into Terminal instead. It does not work on chatgpt.com or in the ChatGPT phone app.

  1. Paste this into Terminal

    curl -fsSL https://github.com/Ruwad-io/askmywa/releases/latest/download/install.sh | sh

  2. Type the code on your phone

    Terminal shows it. WhatsApp › Linked devices › Link a device › Link with phone number instead

  3. Quit and reopen ChatGPT

    The installer added askmywa to ChatGPT and Codex. Ask away in a new chat, and allow askmywa if the app asks.

Privacy

Where your messages go.

Your computer

The local archive.

Messages received from WhatsApp are stored on your computer. WhatsApp may supply only part of your older history.

Your assistant's provider

What it looks up.

Tool results, including message text, contact names and phone numbers, are sent to Anthropic for Claude or OpenAI for ChatGPT and Codex. Their privacy policies apply.

Us

Nothing.

There is no askmywa server, no account and no tracking. The program talks to WhatsApp directly.

Files only from one folder you chooseOpen source, MIT licenseRemoved in one sentencePrivacy policy

Read this before you install.

  • It is not made by WhatsApp. It connects as a linked device, like WhatsApp Web, through an interface WhatsApp has not officially opened. WhatsApp's terms do not allow this, and WhatsApp could restrict or ban an account that uses it.
  • Watch for trick messages. A received message could try to fool the assistant. Sending confirmation relies on the assistant following its instructions: read the preview before approving.
  • Search covers the local archive. Your computer must be on and connected to receive new messages. WhatsApp supplies history and catch-up messages when it reconnects; a complete history is not guaranteed.
  • On Windows, the program isn't code-signed yet. If SmartScreen warns you, choose More info › Run anyway.

For developers

A WhatsApp MCP server in one binary.

Under the extension is an MCP server: askmywa serve speaks MCP over stdio, with 15 typed tools such as list_messages, search_contacts and a send_message that waits for confirmation. On Linux, a Raspberry Pi or a Mac, one command picks the right build, checks it, installs the background service and links WhatsApp with a code. A Pi left on can keep receiving messages while your laptop sleeps. Full guide

On your own server, it can also work for one trusted app: send-only, so it keeps no message; a private HTTP door with a secret and send caps; and a signed webhook for each new message. Server mode and webhooks

$ curl -fsSL https://github.com/Ruwad-io/askmywa/releases/latest/download/install.sh | sh
$ brew install ruwad-io/tap/askmywa
$ askmywa install-service
$ askmywa link
$ claude mcp add whatsapp -- ~/.local/bin/askmywa serve

Questions

Fair questions.

Is it really free?

Yes. Open source under the MIT license, with no account, no subscription and no ads.

Does it work with Claude on my phone?

No. The Claude phone app and claude.ai can't use an extension that lives on your computer. You need the Claude desktop app on a Mac or a Windows PC.

Does it work with ChatGPT?

Yes, in the ChatGPT app on a Mac and in Codex, once installed from Terminal. Not on chatgpt.com or in the phone app, which can't reach a program on your computer.

How is sending approved?

Sending tools preview by default. The assistant is instructed to show you the recipient and content, ask for your approval, then confirm the send. askmywa cannot independently verify that the assistant obtained your agreement.

Can it search all my old messages?

Only messages in this computer's archive can be searched. WhatsApp may send only part of your history when you link a device. Ask your assistant for the oldest and newest stored messages in the chat you care about; a missing search result does not prove a message was never sent.

Will WhatsApp ban my account?

We can't promise it won't. It uses the same kind of connection as WhatsApp Web, through an unofficial interface that WhatsApp's terms don't allow.

How do I remove it?

Ask Claude: “Disconnect WhatsApp from this computer and delete the messages.” Then remove the extension in Claude's Settings › Extensions.

Who makes it?

Open-source software published by RUWAD, a small company in Paris (legal notice). It is not affiliated with WhatsApp, Meta or Anthropic. It started as a rewrite of lharries/whatsapp-mcp. Bugs and questions go to GitHub.
