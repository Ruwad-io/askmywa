Installer

Deux minutes. Un code.

Pas de terminal, pas de QR code. Vous liez votre ordinateur comme pour WhatsApp Web, en tapant un code sur votre téléphone.

Votre code · valable 2 minutes
K7QM-2XPA

Claude vous affiche un code comme celui-ci. Chaque code est nouveau et ne sert qu'une fois.

  1. Téléchargez l'extension

    Un seul fichier, whatsapp-mcp.mcpb, pour Mac et Windows.

  2. Double-cliquez dessus

    Claude s'ouvre et vous demande de confirmer l'installation.

  3. Dites « Connecte mon WhatsApp »

    Dans une nouvelle conversation. Donnez votre numéro avec l'indicatif du pays.

  4. Tapez le code sur le téléphone

    WhatsApp › Appareils connectés › Connecter un appareil › Connecter avec un numéro de téléphone

À lire avant d'installer.

  • Ce n'est pas un produit de WhatsApp. L'extension se connecte comme un appareil lié, à la manière de WhatsApp Web, par une interface que WhatsApp n'a pas officiellement ouverte. Les conditions de WhatsApp ne l'autorisent pas, et WhatsApp pourrait restreindre ou bannir un compte qui l'utilise.
  • Méfiez-vous des messages piégés. Un message reçu pourrait tenter de tromper l'assistant. C'est pour cela que chaque envoi attend votre oui : lisez l'aperçu d'abord.
  • L'ordinateur doit être allumé pour que les nouveaux messages arrivent. Ceux reçus pendant qu'il dort sont rattrapés au réveil.
  • Sous Windows, le programme n'est pas encore signé. Si SmartScreen s'affiche, choisissez Informations complémentaires › Exécuter quand même.

Pour les développeurs

Un serveur MCP WhatsApp en un seul programme.

Sous l'extension, il y a un serveur MCP : whatsapp-mcp serve parle MCP sur stdio, avec 15 outils typés comme list_messages, search_contacts et un send_message qui attend une confirmation. Sous Linux, sur un Raspberry Pi ou sur Mac, une commande choisit la bonne version, la vérifie, installe le service en arrière-plan et lie WhatsApp avec un code. Un Pi laissé allumé garde l'archive complète pendant que votre ordinateur dort. Guide complet

$ curl -fsSL https://github.com/abonur/whatsapp-mcp/releases/latest/download/install.sh | sh
$ brew install abonur/tap/whatsapp-mcp
$ whatsapp-mcp install-service
$ whatsapp-mcp link
$ claude mcp add whatsapp -- ~/.local/bin/whatsapp-mcp serve

Questions

Bonnes questions.

C'est vraiment gratuit ?

Oui. Logiciel libre sous licence MIT, sans compte, sans abonnement et sans publicité.

Ça marche avec Claude sur mon téléphone ?

Non. L'application Claude du téléphone et claude.ai ne peuvent pas utiliser une extension installée sur votre ordinateur. Il faut l'application Claude pour ordinateur, sur Mac ou PC Windows.

Peut-il envoyer des messages tout seul ?

Non. Chaque envoi renvoie d'abord un aperçu. Claude n'envoie qu'après votre accord sur ce message précis.

WhatsApp va-t-il bannir mon compte ?

On ne peut pas promettre que non. L'outil utilise le même type de connexion que WhatsApp Web, par une interface non officielle que les conditions de WhatsApp n'autorisent pas.

Comment le retirer ?

Demandez à Claude : « Déconnecte WhatsApp de cet ordinateur et efface les messages. » Puis retirez l'extension dans Réglages › Extensions de Claude.

Qui est derrière ?

Un projet libre et indépendant, sans lien avec WhatsApp, Meta ou Anthropic. Il est né d'une réécriture de lharries/whatsapp-mcp. Bugs et questions sur GitHub.
