Envoyer

Un aperçu avant l'envoi.

Par défaut, les outils d'envoi renvoient un aperçu : le destinataire et le message ou fichier exact. Votre assistant reçoit la consigne de vous le montrer et de demander votre accord avant de confirmer l'envoi.

La confirmation passe par votre assistant. askmywa n'a pas de fenêtre d'approbation indépendante pour vérifier votre accord. Relisez le destinataire et le contenu avant de dire oui.

Claude Desktop · Mac et Windows

Un fichier. Un code.

Pas de terminal, pas de QR code. Vous liez votre ordinateur comme pour WhatsApp Web, en tapant un code sur votre téléphone.

Votre code · valable 2 minutes
K7QM-2XPA

Claude vous affiche un code comme celui-ci. Chaque code est nouveau et ne sert qu'une fois.

  1. Téléchargez l'extension

    Un seul fichier, askmywa.mcpb, pour Mac et Windows.

  2. Double-cliquez dessus

    Claude s'ouvre et vous demande de confirmer l'installation.

  3. Dites « Connecte mon WhatsApp »

    Dans une nouvelle conversation. Donnez votre numéro avec l'indicatif du pays. Claude demande à utiliser askmywa : choisissez les autorisations qui vous conviennent.

  4. Tapez le code sur le téléphone

    WhatsApp › Appareils connectés › Connecter un appareil › Connecter avec un numéro de téléphone

ChatGPT et Codex

Installer pour ChatGPT ou Codex.

askmywa marche aussi dans l'application ChatGPT sur Mac, et dans Codex. Il n'y a pas encore de fichier à double-cliquer pour ChatGPT : on colle une ligne dans le Terminal à la place. Ça ne marche pas sur chatgpt.com ni dans l'application ChatGPT du téléphone.

  1. Collez ceci dans le Terminal

    curl -fsSL https://github.com/Ruwad-io/askmywa/releases/latest/download/install.sh | sh

  2. Tapez le code sur votre téléphone

    Le Terminal l'affiche. WhatsApp › Appareils connectés › Connecter un appareil › Connecter avec le numéro de téléphone

  3. Quittez et rouvrez ChatGPT

    L'installeur a ajouté askmywa à ChatGPT et à Codex. Posez vos questions dans une nouvelle conversation, et autorisez askmywa si l'application le demande.

Vie privée

Où vont vos messages.

Votre ordinateur

L'archive locale.

Les messages reçus de WhatsApp sont stockés sur votre ordinateur. WhatsApp peut ne fournir qu'une partie de votre ancien historique.

Le fournisseur de votre assistant

Ce qu'il consulte.

Les résultats des outils, dont le texte des messages, les noms et numéros de téléphone, sont transmis à Anthropic pour Claude ou à OpenAI pour ChatGPT et Codex. Leurs politiques de confidentialité s'appliquent.

Nous

Rien.

Il n'y a ni serveur askmywa, ni compte, ni pistage. Le programme parle directement à WhatsApp.

À lire avant d'installer.

  • Ce n'est pas un produit de WhatsApp. L'extension se connecte comme un appareil lié, à la manière de WhatsApp Web, par une interface que WhatsApp n'a pas officiellement ouverte. Les conditions de WhatsApp ne l'autorisent pas, et WhatsApp pourrait restreindre ou bannir un compte qui l'utilise.
  • Méfiez-vous des messages piégés. Un message reçu pourrait tenter de tromper l'assistant. La confirmation d'envoi repose sur le respect de ses consignes par l'assistant : lisez l'aperçu avant de donner votre accord.
  • La recherche porte sur l'archive locale. Votre ordinateur doit être allumé et connecté pour recevoir les nouveaux messages. WhatsApp fournit l'historique et les messages de rattrapage à la reconnexion ; un historique complet n'est pas garanti.
  • Sous Windows, le programme n'est pas encore signé. Si SmartScreen s'affiche, choisissez Informations complémentaires › Exécuter quand même.

Pour les développeurs

Un serveur MCP WhatsApp en un seul programme.

Sous l'extension, il y a un serveur MCP : askmywa serve parle MCP sur stdio, avec 15 outils typés comme list_messages, search_contacts et un send_message qui attend une confirmation. Sous Linux, sur un Raspberry Pi ou sur Mac, une commande choisit la bonne version, la vérifie, installe le service en arrière-plan et lie WhatsApp avec un code. Un Pi laissé allumé peut continuer à recevoir les messages pendant que votre ordinateur dort. Guide complet

$ curl -fsSL https://github.com/Ruwad-io/askmywa/releases/latest/download/install.sh | sh
$ brew install ruwad-io/tap/askmywa
$ askmywa install-service
$ askmywa link
$ claude mcp add whatsapp -- ~/.local/bin/askmywa serve

Questions

Bonnes questions.

C'est vraiment gratuit ?

Oui. Logiciel libre sous licence MIT, sans compte, sans abonnement et sans publicité.

Ça marche avec Claude sur mon téléphone ?

Non. L'application Claude du téléphone et claude.ai ne peuvent pas utiliser une extension installée sur votre ordinateur. Il faut l'application Claude pour ordinateur, sur Mac ou PC Windows.

Ça marche avec ChatGPT ?

Oui, dans l'application ChatGPT sur Mac et dans Codex, une fois installé depuis le Terminal. Pas sur chatgpt.com ni dans l'application du téléphone, qui ne peuvent pas joindre un programme installé sur votre ordinateur.

Comment l'envoi est-il approuvé ?

Les outils d'envoi montrent un aperçu par défaut. L'assistant reçoit la consigne de vous montrer le destinataire et le contenu, de demander votre accord, puis de confirmer l'envoi. askmywa ne peut pas vérifier indépendamment que l'assistant a obtenu votre accord.

Peut-il chercher dans tous mes anciens messages ?

Seuls les messages de l'archive de cet ordinateur sont consultables. WhatsApp peut ne transmettre qu'une partie de l'historique à la connexion. Demandez à l'assistant les messages stockés les plus anciens et les plus récents du groupe concerné ; un résultat absent ne prouve pas qu'un message n'a jamais été envoyé.

WhatsApp va-t-il bannir mon compte ?

On ne peut pas promettre que non. L'outil utilise le même type de connexion que WhatsApp Web, par une interface non officielle que les conditions de WhatsApp n'autorisent pas.

Comment le retirer ?

Demandez à Claude : « Déconnecte WhatsApp de cet ordinateur et efface les messages. » Puis retirez l'extension dans Réglages › Extensions de Claude.
